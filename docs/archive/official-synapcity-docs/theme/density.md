# Density

Density controls how compact or spacious the interface feels.

---

## Modes

- Compact
- Default
- Comfortable

---

## Affected Areas

- card padding
- table row height
- toolbar height
- sidebar item height
- rail spacing
- popover padding
- grid gaps
- form control height

---

## Rules

- Density should not change information hierarchy.
- Compact mode must remain accessible.
- Comfortable mode should not become visually loose or decorative.
- Components should consume density tokens rather than hardcoding per-mode values.
