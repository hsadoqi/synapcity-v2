# Repository investigation

Read only. Do not modify files.

1. Read `AGENTS.md`, then follow its read order for the task. Do not read the whole docs tree for a narrow task.
2. Check current state: `git status`, `git log --oneline -5`, the relevant issue (`gh issue view N`), and the ADR index with its candidate list.
3. Separate three things: decided (cite the canonical document), unresolved (cite where it is marked open), and not covered.
4. Measure instead of assuming: run the relevant command, read the file, query the setting.
5. List files likely to change, risks, and conflicts between documents.

Report: what is required, what is established, what is unresolved, constraints, affected files, risks, and questions that need the human's approval.
