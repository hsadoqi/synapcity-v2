# @synapcity/server-data

Owns: the Space, document and dashboard queries and writes against a Supabase request client the host supplies (ADR-0012, ADR-0013). Reads the owner's Spaces, documents and dashboards, and the documents and dashboards that take part in one Space; creates all three from a name, and writes pinned on all three and last viewed on Spaces. The document and dashboard reads and the pin write moved here from `apps/web/src/lib/owned-records` before Milestone 8 (owner decision, 2026-10-27), which builds on `records/`.

Runtime: server only. The root file starts with `import 'server-only'`, and no other file in the package imports it. Dependencies: `@synapcity/domain-records` for the base record contract and `@synapcity/domain-spaces` for the Space contract, `@synapcity/server-supabase` for the typed client and `toProviderFailure`, `zod`. Category rules: [server README](../README.md) and [ADR-0014](../../../docs/architecture/decisions/0014-multi-app-package-boundaries.md).

## Public interface

`@synapcity/server-data` (root entry). Every function takes the request client first:

| Export                                       | Meaning                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| `listSpaceSummaries(client)`                 | The same with `documentsTotal` and `dashboardsTotal` from the participation tables                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `findSpace(client, spaceId)`                 | One Space, or `null` when it does not exist, is not theirs, or the id is not a UUID (no query is made for a malformed id)                                                                                                                                                                                                                                                                                                                                                                                  |
| `setSpacePinned(client, spaceId, pinned)`    | `setRecordPinned` for the `spaces` table                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `recordSpaceView(client, spaceId, now)`      | `{ ok: true }` or `{ ok: false, error }` (code and status only); skipped when the last view is under a minute old                                                                                                                                                                                                                                                                                                                                                                                          |
| `listRecordSummaries(client, kind)`          | The owner's `documents` or `dashboards` as `OwnedRecordSummary[]` (with `spacesTotal`), newest first                                                                                                                                                                                                                                                                                                                                                                                                       |
| `findRecord(client, kind, id)`               | One of the owner's `documents` or `dashboards` as `BaseRecord`, or `null` when it does not exist, is not theirs, or the id is not a UUID (no query)                                                                                                                                                                                                                                                                                                                                                        |
| `setRecordPinned(client, table, id, pinned)` | Pins or unpins a row of `spaces`, `documents` or `dashboards`: `{ ok: true, pinnedAt }` with the database-stamped time, or `{ ok: false, error }` with code and status only; a write row-level security turned away is `row_not_written`. Types `PinnedOutcome`, `RecordKind`                                                                                                                                                                                                                              |
| `createRecord(client, table, { name })`      | Creates a row of `spaces`, `documents` or `dashboards` with only its name; the owner and every other column come from the database's defaults. `{ ok: true, id }`, or `{ ok: false, error }` with code and status only. ## Rules

- Row-level security scopes every query. No owner id is passed to any function.
- The package never logs and never reads `NODE_ENV`, fixture mode or any other environment. Hosts log by code and status only and decide when fixtures apply.
- A participation row whose item the caller cannot see is skipped, not an error.
- Per-Space `pinned` and `position` on the participation rows are not read yet. They arrive with the feature that shows them.
- Row types and row mapping are private to the package (`owned-row`, shared by the three tables). Rows are typed from the generated `Database`; each query is a literal select, one per kind, so the generated types check it.
- Reads a page needs throw, so the route's error page handles them. The thrown message names the read and the error code only (`Failed to load spaces (code 42501)`), never the database's message. Writes return outcomes and never throw for a database error.
